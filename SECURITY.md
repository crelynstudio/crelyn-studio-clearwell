# Security / Güvenlik

This unsigned preview is under development. Stable production support is not claimed. Use disposable Windows VMs for system mutation testing. Keep Windows security enabled.

Report suspected vulnerabilities privately to [info@crelynstudio.com](mailto:info@crelynstudio.com). Include Clearwell version, Windows version, reproducible steps and impact. Remove user names, personal paths, secrets and real recovery data. Do not publish an exploit or sensitive attachments in public issues. A local support export is available in Change history; review it before sending. No response-time guarantee is made.

Only the latest preview is maintained. Back up local recovery records before upgrades; source/ZIP checksums are not code signatures. File deletion is permanent; cancellation is not installer rollback.
