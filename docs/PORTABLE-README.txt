CLEARWELL 0.2.0-preview.1 — WINDOWS X64 DEVELOPMENT PREVIEW

Run Clearwell.exe. The .NET runtime is included. Keep all included license and
notice files with the executable. The build is unsigned. This approved preview
is not a stable release. Windows 10 is a target, not yet verified.

Start with normal user access. Scan is read-only. Review and confirm each
operation. The system overview reads actual CPU, active graphics adapter,
Windows, physical memory and fixed-volume usage. Refresh is on demand.
Search finds pages, apps, preferences and Windows tools. The catalog supports
112 applications across eight categories, category/name filters and a reviewed queue that stops at
the first failure. Completed installs remain; no automatic rollback occurs.

Review and confirm each
change. Cleanup permanently deletes files; it has no undo. Prefetch and crash
dumps are unselected by default. Recent, locked, changed and linked files are
excluded. The scanner uses standard Windows/user Temp locations only.

Preference and power changes are recorded for undo in Change history. This is
not a system backup. Restart/sign-out may be needed; Windows policies may
override preferences. Other programs' changes are not overwritten by undo.
Normal-use data: %LOCALAPPDATA%\CrelynStudio\Clearwell .

No network is needed for the interface, cleanup, preferences or power controls.
WinGet application installation needs internet and accepts third-party source
and package terms after confirmation. Installers can show UAC or dialogs.
Install/uninstall has no automatic undo. Native installer output can use the
Windows language. No analytics, background agent, login or API key is included.

Try: language/theme switching and persistence; resizing and keyboard focus;
read-only scan; review then cancel; startup and power-plan discovery.
Test actual cleanup, preference recovery, power switching, UAC and installers
in a disposable VM before trusting the preview on a valuable installation.
These live changes were not executed on the developer's/user's main computer.
Manual Windows 10, screen-reader, high-DPI and multi-monitor checks are pending.

inceleyip onaylayın. Temizlik kalıcı siler; geri alma yoktur. Prefetch ve çökme
