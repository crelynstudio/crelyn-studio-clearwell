CLEARWELL @VERSION@ — WINDOWS X64 DEVELOPMENT PREVIEW

Close the old app. Extract into a new folder, keep all license/notice files
and run Clearwell.exe. .NET is included. This unsigned preview is not a stable
release. Do not disable Windows security. Verify ZIP SHA-256 against its
.zip.sha256 file; a hash is not a signing certificate.

Back up %LOCALAPPDATA%\CrelynStudio\Clearwell before upgrading. Legacy history
loads; new writes use schema 1. Do not downgrade to 0.2 with the updated
profile. A profile backup does not undo subsequent Windows changes.

Start with normal user access and read-only scanning. Review individual files
and exclude important ones. Keep 1/7/30 days (default 7). Deletion is permanent:
no quarantine, recycle bin or undo. Prefetch/crash dumps/validated redirected
TEMP remain unselected. Linked, locked, changed/replaced and recent files are
protected. Partial scans need extra confirmation. CSV contains full paths.

Settings/power changes save originals for undo. Activity retains 200 local
operations without file paths/installer output. Export platform/error details
locally; nothing is uploaded automatically. Archive only already-undone records.
Preserve recovery files if you need undo. This is not a system backup.

WinGet needs source/network availability and reviewed third-party terms.
Cancellation requests a stop, not rollback; detached/elevated installers may
continue. Inspect actual state before retrying. The queue stops on errors or
unverified inventory. Optional Store/MSIX inventory is current-user only.
Startup inspection is partial.

UI/cleanup/local settings work offline after installation. No account, API key,
analytics, CDN or background agent. Windows 11 is locally exercised. Windows 10,
live settings/power/UAC/install/uninstall VM scenarios, screen readers, physical
mixed DPI and high contrast remain unverified. Test live mutations in a
disposable VM. ARM64/x86 packages are not supplied.

TÜRKÇE — WINDOWS X64 GELİŞTİRME ÖNİZLEMESİ

Eski uygulamayı kapatın. ZIP'i yeni klasöre açın; tüm lisans/bildirimleri koruyun,
Clearwell.exe çalıştırın. .NET dahildir. İmzasız önizleme kararlı sürüm değildir.
Windows güvenliğini kapatmayın. ZIP SHA-256 değerini .zip.sha256 ile kontrol edin;
hash kod imzası değildir.

Önce %LOCALAPPDATA%\CrelynStudio\Clearwell klasörünü yedekleyin. Eski geçmiş
okunur; yeni yazımlar şema 1 kullanır. Güncellenmiş profille 0.2'ye dönmeyin.
Profil yedeği sonraki Windows değişikliklerini geri almaz.

Standart yetki ve salt okunur taramayla başlayın. Tekil dosyaları inceleyin,
önemli olanları hariç tutun; 1/7/30 gün koruyun (varsayılan 7). Silme kalıcıdır;
karantina/Geri Dönüşüm Kutusu/geri alma yoktur. Prefetch, çökme dökümleri ve
doğrulanmış özel TEMP seçili değildir. Bağlantılı/kilitli/değişmiş/değiştirilmiş/
yeni dosyalar korunur. Kısmi tarama ek onay ister. CSV tam yollar içerir.

Ayar/güç özgün değerleri geri alma için kaydeder. Son 200 yerel etkinlik yolu/
kurucu çıktısını içermez. Destek raporu platform/hata ayrıntısını yerelde aktarır;
otomatik gönderim yoktur. Arşiv yalnız geri alınmış kayıtları ayrı yerel dosyada
korur. Geri alma için kurtarma dosyalarını saklayın. Sistem yedeği değildir.

WinGet kaynak/ağ erişimi ve incelenmiş üçüncü taraf koşulları ister. İptal geri
alma değildir; ayrılmış/yükseltilmiş kurucular devam edebilir. Gerçek durumu
kontrol edin. Hata/doğrulanamayan envanterde sıra durur. Store/MSIX yalnız geçerli
kullanıcıyı kapsar; başlangıç incelemesi kısmidir.

Arayüz/temizlik/yerel ayarlar kurulumdan sonra çevrimdışıdır. Hesap/API anahtarı/
analitik/CDN/arka plan hizmeti yoktur. Windows 11 yerelde denendi. Windows 10;
canlı ayar/güç/UAC/kurma/kaldırma; ekran okuyucu/fiziksel karma DPI/yüksek kontrast
doğrulaması bekler. Gerçek değişiklikleri gözden çıkarılabilir VM'de sınayın.
ARM64/x86 paketi yoktur.
