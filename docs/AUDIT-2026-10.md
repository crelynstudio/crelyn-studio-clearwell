## Validation boundary / Doğrulama sınırı

Locally run: locked restore, warning-as-error build, assert-based fixture checks, WPF isolated-profile rendering and cancellation, read-only hardware/power/desktop/Store reads, full 112-ID source health check, portable extraction/version/checksum/UI verification. The final owner handoff lists exact results. Local evidence is not evidence of a GitHub-hosted run or Windows 10 support.

Yerelde: kilitli restore, uyarıyı hata sayan derleme, fixture kontrolleri, yalıtılmış WPF görünüm/iptal, salt okunur donanım/güç/masaüstü/Store, 112 kaynak sorgusu ve bağımsız taşınabilir paket/hash/arayüz kontrolü. Kesin sonuçlar teslim rehberinde kaydedilir. Yerel başarı GitHub CI veya Windows 10 kanıtı değildir.

## Live acceptance matrix still required / Gereken canlı kabul matrisi

Use separate Windows 10 22H2 and Windows 11 VMs with a clean snapshot. Record OS/build, account type, Clearwell version, before/after values and evidence. Revert the snapshot between cases. Never run destructive acceptance against an important host.

Ayrı Windows 10 22H2 ve Windows 11 VM'de temiz anlık görüntü kullanın. Sistem/derleme, hesap türü, uygulama sürümü, önce/sonra değerleri ve kanıtı kaydedin. Senaryolar arasında anlık görüntüye dönün; önemli ana cihazda yıkıcı kabul testi yapmayın.
